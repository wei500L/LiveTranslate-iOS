# Backend Comparison

同一 GigaAM-v3 `e2e_rnnt` 模型、两个本地推理后端的对比方法与实测结果。

## 方法

`ASRBenchmarkRunner` **顺序**执行（绝不同时驻留两个后端）：

1. 加载 Core ML → 对全部测试音频推理 → 保存结果与性能 → 卸载 → 确认内存释放
2. 加载 sherpa-onnx → 对相同音频推理 → 保存 → 卸载
3. 生成报告（可导出 Markdown/JSON）

测试音频来源：App 内置俄语测试音频（本地 TTS 生成）、现场录制、文件 App 导入 WAV/M4A、批量课堂片段；可选人工参考文本。

## 报告字段

两后端完整转录、是否完全一致、字符差异、规范化 CER（互为参考）、去标点 CER、有人工参考时各自 CER/WER、加载时间、首次/热推理时间、音频时长、RTF、峰值内存、热状态、Core ML 计算单元、INT8 线程数、模型版本、设备、iOS 版本、测试时间。

**没有人工参考文本时，只描述输出差异，不宣称谁更准确。**
