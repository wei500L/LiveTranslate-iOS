# 离线翻译与图片理解（On-Device Models）

俄语课堂转录 → 简体中文翻译可以**完全离线**完成。本页面向用户与审阅者说明：模型从哪里来、如何下载/切换/删除、断网时的行为、失败时的兜底，以及磁盘与许可注意事项。

模型文件**不随 App 打包、不进 Git**——首次使用前从固定 revision 的 Hugging Face 仓库下载（SHA256 逐文件校验），详见 `docs/MODEL_DISTRIBUTION.md`。

## 用户操作路径

1. **下载**：我的 → 翻译设置 → 翻译模型管理 → 对应模型卡片 → 下载。支持暂停/继续（断点续传）、失败重试、校验、删除。
2. **选择**：设置 → 翻译方式选择「离线 · 标准画质」（默认）或「离线 · 省电模式」。已配置云端 API 的老用户保持云端不变。
3. **切换**：非课堂进行时随时切换；课堂进行中模型被锁定到会话结束（保证同一场课堂的译文来自同一模型，且不影响已保存记录）。结束课堂时会等待已进入流水线的翻译全部收尾后再解锁。
4. **使用**：开始课堂即可。断网状态下照常转录+翻译（界面不显示离线提示；云端方式才会显示）。
5. **图片理解**：下载 Gemma 模型后，课堂拍照分析、资料图片理解/视觉问答自动走本地模型；未下载时维持原有云端路径。模型只在有图片请求时加载、用完即释放。

## 失败与兜底

- **俄语原文永远先落库**：ASR 完成即保存，任何翻译失败都不会丢失转录。
- **本地模型加载/推理失败**：该条目标记为可重试失败（可手动重试）；配置为系统翻译兜底（iOS 26+）时，单条请求自动降级到 Apple Translation 并在活动日志留痕。iOS 17–25 无系统翻译兜底（诚实显示失败）。
- **磁盘不足**：下载前检查（Hy-MT2 ≥ 1.4 GB、MiLMMT ≥ 1.0 GB、Gemma ≥ 3.1 GB 可用空间），不足即报错，不会开始半截下载。
- **文件损坏**：SHA256 校验失败自动删除损坏文件并可重新下载；安装后可随时「重新校验」。

## 资源生命周期（与常驻模型的关系）

- 文本翻译模型在课堂期间**常驻**（加载一次，逐句推理），会话结束不卸载（下节课免重载）。
- 图片理解模型**绝不常驻**：每次图片请求开始时加载、结束后立即释放，与翻译模型的内存互不叠加。
- 任何时刻最多**一台**翻译模型常驻：切换即完全卸载旧模型再加载新模型。
