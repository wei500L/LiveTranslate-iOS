# Privacy

LiveTranslate iOS 的数据处理边界。逐节如实描述 —— 不使用"端到端加密"
之类的措辞描述并非如此的事实。

## 麦克风音频

- 麦克风输入在 **iPhone 本地**完成全部语音识别（GigaAM-v3，Core ML 或 sherpa-onnx/ONNX Runtime，均在本机运行）。
- 音频样本不会发送到任何服务器。
- 默认**不保存**原始音频。设置中开启"保存原始录音"后，录音仅写入本机 App 沙盒，可随时在设置中删除。
- App 不会在后台自动开启麦克风；每次录音会话都由你点击"开始"显式发起。会话期间进入后台/锁屏，录音会继续（已声明音频后台模式），停止按钮随时可用。

## 文本与文件

- 只有**俄语识别文本**（不是音频）会发送给你自己配置的翻译 API 端点。
- 课堂记录（俄语原文与中文译文）保存在本机 SwiftData 数据库；登录后按你的选择同步到**你自己的**自建服务器。
- **随身翻译的现场文件（证件、表格、PDF、扫描件）只保存在这台设备**：不进云同步、不进设备/iCloud 备份、不进入任何系统界面。服务器上只有对话文本 —— 第十七轮起连文件名、页码与引文都不上传（来源标签只保存在原设备）。
- 你可以删除任何单场记录或全部记录；删除分三层（清缓存 / 删本机记录 / 删云端数据），见设置 → 隐私与数据。

## 密钥

- 翻译 API Key 与同步 token 仅存储在 iOS Keychain（`kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`）：不写入 UserDefaults、不导出、不进入日志，也**不随设备备份迁移**（新设备需重新登录/重新配置 Key）。
- 导出的任何文件（Markdown/TXT/JSON/SRT/对比报告）都不包含 API Key、Authorization 头或内部路径。

## 日志

- 日志（OSLog）对端点、模型名做脱敏；绝不记录 API Key、请求头、请求正文或模型响应正文。
- **AI 数据活动记录**（设置 → 隐私与数据）只记录时间、功能、数据类别、字符/图片数量、是否遮盖、结果与服务商地址；仅保存在本机，30 天后自动清除，可随时清空，不进入同步或系统日志。这是本机台账，不是服务商侧审计。

## 文件保护（第十七轮）

- 锁屏后不可访问（NSFileProtectionComplete）：随身翻译文件、智能收件箱条目、各类可重建缓存、临时导出。
- 锁屏后台课堂仍可写（CompleteUntilFirstUserAuthentication）：SwiftData 数据库、同步队列、课堂录音、ASR 模型文件 —— 后台课堂与 45 秒同步循环依赖此等级。
- 文件保护不等于端到端加密：它把文件访问绑定到设备锁状态；解锁状态下打开的 App 与正常使用不受影响。

## 隐私锁与遮挡（第十七轮）

- 可选的**隐私锁**：Face ID / 触控 ID / 设备密码（系统生物认证，无自定义 PIN）。默认关闭；开关与解锁状态只保存在本机，不同步、不跨账号；切换账号立即重新锁定。
- **后台预览遮挡**：切到任务切换器时界面被品牌占位层覆盖，系统快照不显示课堂转录或文件内容。默认开启。
- **录屏与镜像遮挡**：检测到系统录屏/投屏时遮挡随身翻译、给对方看模式与账号安全页。iOS 无法阻止截图 —— 任何声称"已阻止截图"的 App 都在说谎；我们只在检测到**持续捕获**时遮挡，并如实告知截图风险。
- **系统界面内容级别**：一个三档设置（完整内容 / 仅标题 / 仅状态）统一控制锁屏实时课堂、灵动岛、小组件、通知正文、Spotlight 与 Siri 快捷指令回显。转录正文、OCR 与证件内容从不进入任何系统界面。

## 剪贴板（第十七轮）

- 所有复制均**仅本机**（不参与跨设备接力）。
- 敏感内容（翻译、俄语回复、OCR、转录）复制后 **2 分钟自动失效**；普通短语（如公式）不过期。
- 你之后复制的其他内容不会被本 App 清除；主动清除会校验剪贴板仍是我们写入的内容。

## 系统能力边界

- 普通 iOS App 无法捕获其他 App 的内部音频；本 App 只使用麦克风输入。
- 无任何云端 ASR 回退：断网时识别继续，翻译暂停并在网络恢复后重试。
- App 无法阻止截图；录屏检测只覆盖系统录屏/镜像状态。

## 权限

- **麦克风**（NSMicrophoneUsageDescription）：用于课堂与随身翻译的语音识别；拒绝后无法使用实时听写。
- **相机**（NSCameraUsageDescription）：拍摄黑板、幻灯片与随身翻译的现场文件（表格/通知/证件）。照片保存在本机，登录后附件可按你的选择同步到自建服务器。
- **日历（只写）**（NSCalendarsWriteOnlyAccessUsageDescription）：把考试与学习计划加入你选择的日历。只在点击"加入系统日历"时请求；App 从不读取你的日历。
- **Face ID**（NSFaceIDUsageDescription）：开启隐私锁后用于解锁 App；仅在设置 → 隐私与数据中主动开启时才会提示。
- 通知提醒为运行时请求（无 Info.plist 键）：上课/作业/考试提醒与每日学习汇总。
- 未使用：照片库完全访问（PhotosPicker 无需权限）、语音识别（SFSpeechRecognizer）、通讯录、位置、蓝牙、本地网络发现（自定义 API 端点直连 ATS 放行的局域网地址，不触发本地网络隐私弹窗）。
